
# Proyecto "aprende jugando"

Este proyecto se desarrolló con el objetivo de mejorar el aprendizaje en niños de 4 a 6 años mediante un juego interactivo educativo, utilizando mecánicas de gamificación para potenciar la comprensión de conceptos básicos en matemáticas, lenguaje y lógica.


## 🚀 Características principales
✅ Aprendizaje basado en juegos interactivos.  
✅ Gamificación para mejorar la retención de conocimientos.  
✅ Adaptado para niños de 4 a 6 años.  
✅ Interfaz intuitiva y colorida.  
✅ Compatible con dispositivos Android.  
## 🛠 Tecnologías utilizadas
- 🎮 **Desarrollo del juego:** Unity (versión 2022.3.37f1)  
- 💻 **Lenguaje de programación:** C#  
- 🔄 **Integración y Despliegue:** Jenkins (CI/CD)  
## 🖥 Instalación y configuración

### 1️⃣ **Requisitos previos**
- Necesitas tener **Unity 2022.3.37f1** instalado. Puedes descargarlo desde [aquí](https://unity.com/download).
- Tener instalado **Git** para clonar el repositorio.

### 2️⃣ **Clonar el proyecto**
Ejecuta el siguiente comando en la terminal:

```bash
git clone https://github.com/MLxFernando/proyecto-aprende-jugando.git
```
### 3️⃣ **Abrir en Unity**
Abre Unity Hub y selecciona "Abrir Proyecto".
Busca la carpeta donde clonaste el repositorio.
Asegúrate de que la versión de Unity sea la correcta.
### 4️⃣ **Ejecutar el juego**
Dentro de Unity, selecciona "Play" en la barra superior.
¡Listo! Puedes probar el juego y explorar sus funcionalidades.
